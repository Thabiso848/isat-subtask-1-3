# Mobile Phone RF Detector — Design Concept

**Status:** Concept schematic only. It has not been verified as a build-ready circuit or tested on hardware.

## Design idea
The diagram represents a proposed RF pickup and indicator circuit using an antenna, LM358 op-amp, BC337 transistor and LED. It is a planning artefact, not a confirmed working detector.

## File
- [mobile_phone_detector_concept.drawio](mobile_phone_detector_concept.drawio) — editable diagrams.net / Draw.io file.

## Important
The exact LM358 input and feedback network must be checked against a valid circuit design before connecting power. RF detection depends on the phone's radio transmissions and network behaviour; this should not be presented as detecting every phone or every call.
